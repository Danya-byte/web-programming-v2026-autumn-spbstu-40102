# Лабораторная работа 3

## Задание

Вариант 23. Реализовать функцию `findLongestIncreasingSubsequence(arr)`, которая
находит длину наибольшей возрастающей подпоследовательности.

## Реализация

Функция `findLongestIncreasingSubsequence` экспортируется из `solution.js` как
именованный ES module export. Решение использует динамическое программирование и
не изменяет исходный массив.

## Запуск

Импортируйте именованный export `findLongestIncreasingSubsequence` из файла
`solution.js` как ES module.
