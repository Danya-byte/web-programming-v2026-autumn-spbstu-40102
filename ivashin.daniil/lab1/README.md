# Лабораторная работа 1

## Задание

Вариант 23. Создать регистрационную форму с полями для имени, фамилии,
электронной почты, пароля, подтверждения пароля, даты рождения и пола, а также с
кнопкой отправки. Для полей используются подходящие значения атрибута `type`.

## Реализация

В файле `index.html` создана семантическая форма с подписями `label`, текстовыми
полями, полем электронной почты, защищёнными полями пароля, выбором даты,
радиокнопками пола и кнопкой отправки.

В файле `styles.css` задано расстояние `10px` между элементами формы, фон формы
`#f2f2f2` и цвет текста `#333`. Добавлены базовые состояния `hover` и `focus`
для кнопки, а также адаптивные отступы для небольших экранов.

## Запуск

В консоли вводим команду: py -m http.server 8000 --directory
.\ivashin.daniil\lab1 Далее в браузере открываем локал хост на указанном порту,
в нашем случае это порт 8000, значит полный вид урл будет http://localhost:8000/
