# Лабораторная работа 2

## Задание

Вариант 23. Реализовать функцию, которая генерирует случайный HEX-цвет, например
`#FF0033`.

## Реализация

Функция `generateHexColor` экспортируется из `solution.js` как именованный ES
module export и возвращает строку формата `#RRGGBB`.

## Запуск

Импортируйте именованный export `generateHexColor` из файла `solution.js` как ES
module.
